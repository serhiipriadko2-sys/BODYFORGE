# BODYFORGE · Кузница тела · MVP v0.2

Фитнес-RPG в визуальном стиле кузницы: графит, горячая сталь, молот и искры. Реальные приседания развивают человека-персонажа. В первой версии работают **вертикальная камера 9:16**, испытание на 20 приседаний, автоматический финиш, **120 XP + 35 монет** и история тренировок.

## Локальный запуск

Требуется Node.js 22+ и npm.

```bash
npm ci
npm run dev
```

Откройте адрес Vite (обычно **http://localhost:5173**). Разрешите использование камеры.

## Проверка

```bash
npm test
npm run build
```

Для камеры нужна безопасная среда: **HTTPS или localhost**. Открыть локальный HTTP-сервер по IP с другого телефона недостаточно — браузер может заблокировать камеру. Для телефона используйте HTTPS-хостинг либо доверенный HTTPS-туннель.

## Как выполнять испытание

1. Поставьте телефон **вертикально**, устойчиво, сбоку от себя. В кадре 9:16 должны целиком помещаться таз, колени и стопы.
2. Нажмите «Начать закалку» и разрешите доступ к камере.
3. Встаньте боком и выпрямите ноги — это калибрует счётчик и запускает секундомер.
4. Сделайте 20 полных приседаний. Для зачёта требуется достаточная глубина и полное выпрямление ног. При включённом звуке каждый засчитанный повтор сопровождается коротким сигналом.
5. После 20-го повтора счётчик сам завершит занятие, остановит таймер, отключит камеру и начислит награду. Сигнал последнего повтора двойной.

## Камера в портретном формате

- Запрос браузеру: предпочтительный поток **720 × 1280**, `aspectRatio: 9 / 16`, фронтальная камера (если доступна).
- Окно на экране всегда вертикальное **9:16** и на смартфоне, и на компьютере. Видео и скелет используют одинаковое `object-fit: cover`.
- Браузер может **не выполнить пожелания** к разрешению: горизонтальная веб-камера отдаст широкое видео, центральная часть будет показана в портретном окне. При этом приложение показывает предупреждение. Чтобы не обрезать человека, встаньте по центру и подберите расстояние.
- На узком экране активное окно прокручивается в центральную область для видимости счётчика.

## Архитектура

- React + TypeScript + Vite: UI.
- MediaPipe Pose Landmarker: 33 точки тела в браузере.
- `src/lib/camera.ts`: настройки портретной камеры и определение фактической ориентации.
- `src/forge.css`: кузнечный стиль (уголь, сталь, медь и жар), мобильная портретная компоновка.
- `src/lib/squatCounter.ts`: чистый алгоритм определения повторений по углу колена; при длительной потере отслеживания требует повторной калибровки, сохраняя уже засчитанные повторы. Тестируемый без камеры.
- `src/lib/progression.ts`: XP, монеты, уровни, лучший результат и локальное сохранение.
- `src/components/Avatar.tsx`: SVG-человек, меняющий пропорции и рельеф мышц по мере тренировок.
- `src/App.tsx`: работа с камерой и её отключением, загрузкой модели, рисованием скелета, таймером, звуковыми сигналами и автоматическим завершением.

## Приватность и ограничения MVP

- Видео **не загружается на сервер и не сохраняется**. Детекция проходит на устройстве.
- Модель позы загружается из Google Cloud Storage, файлы WebAssembly — из CDN jsDelivr. При первом запуске нужен интернет. Не добавляйте в проект токены и `.env`.
- Прогресс сохраняется **только в localStorage этого браузера**. Очистка данных браузера удалит его.
- Это прототип счётчика, не медицинская проверка техники. Угол колена зависит от ракурса, света, одежды и видимости суставов. Возможны пропуски/ложные срабатывания; при обрезке боков широкого видео центрируйте человека. Скоростной PvP пока не поддерживается.
- Дополнительные функции (аккаунты, серверная синхронизация, PvP, магазин, другие упражнения) специально оставлены за пределами MVP.

## Quality gates

Сборка и unit-тесты удостоверяют корректность кода, **но не доказывают** точность подсчёта на всех людях. До реального выпуска нужно проверить счётчик на разных ростах/телосложениях и смартфонах, в том числе частичные приседания, нестабильное освещение и выход из кадра.

## Проверка на реальной камере — ещё не пройдена

После автоматических тестов необходимо провести полевые испытания. Для каждого теста запишите устройство, браузер, освещение, ракурс, ожидаемый счёт и фактический счёт. Видео записывать и отправлять не требуется.

1. **20 полных приседаний:** ровно 20 засчитанных повторений, автоматическая остановка камеры и ровно одна награда.
2. **5 неполных приседаний:** ни одного ложного зачёта (реальная глубина по видео пока не валидирована).
3. **Потеря кадра:** во время приседания уйдите из кадра минимум на 1 секунду и вернитесь стоя. Незавершённое повторение не должно засчитаться; уже выполненные сохраняются.
4. **Отключение камеры:** выключите камеру во время испытания. Приложение должно показать ошибку и не начислять награду.
5. **Два ракурса / два освещения:** сравните счёт с подсчётом человека; зафиксируйте расхождения и условия.

**Не считать PASS по реальной точности**, пока тесты не проведены на людях. Датчик измеряет проекцию коленного угла, но не подтверждает безопасность техники упражнения.

## Если камера не работает

Проверьте разрешение камеры, отсутствие блокировки другим приложением, HTTPS/localhost и доступ к CDN модели. Для ПК лучше использовать боковой ракурс на расстоянии, позволяющем видеть ноги целиком.
