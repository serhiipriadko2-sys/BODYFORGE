# BODYFORGE — новая анатомическая основа, локальный этап 2026-11-27

**PARTIAL / REVIEW ONLY.** Исходный HEAD 11d51edf407bed2ad7e1fd0a04332654fe46afcb. Новая модель не заменяет штатного персонажа и не публиковалась. Разработано в текущем рабочем дереве с параллельными изменениями владельца; не выполнять git reset / clean.

## Источник и результат
Human Base Meshes v1.4.1, Body Male - Realistic, Dan Ulrich, CC0. Официальное зеркало, 50 643 039 байт, CRC всех 29 записей архива PASS. Собственный SHA-256 в RECEIPT; авторская контрольная сумма не найдена. Сборка V3 сохраняет восемь независимых геометрических каналов на 42 342 вершинах master и 19 костях. На каждый игровой уровень t=level/5 объём=t, рельеф=0.65t+0.35t². Рельеф — художественный, не прогноз гипертрофии. V2 добавляет 24 UDIM-сектора нормалей (PNG IHDR 3072×2048; поле height в раннем normal-bake.json ошибочно, фактический файл и V2 measurements корректны), окраску, глаза, волосы, одежду и обувь.

## Доказательства
- 2592 комбинации двух телосложений на master в исходной позе: 0 новых пересечений в swept ROI, 0 severe, все шаги увеличивают рассчитанный объём; 245 исходных пересечений вне ROI. Это не тест всей анимации и одежды.
- 32 позиционные morph targets неизменны относительно V2 и сырого V3; 85 наборов атрибутов/индексов неизменны; 164 accessor декодированы. Первоначальная гипотеза о значимом spill нормалей не подтвердилась при пороге 1e-5. Локальный пересчёт исключает ненужные дельты; GLB уменьшен до 15 400 816 байт. Попытки bone-parenting отклонены из-за изменения положения подошвы; исходные веса сохранены.
- lean: 192 проверки, 20 покупок, аппаратная GPU, 22 скриншота, реальное изменение весов GPU, включение/выключение рельефа при неизменном объёме, fallback при заблокированном GLB без изменения сохранения синтетического профиля.
- solid: 20 покупок и отдельные измерения на всех группах PASS; полный тест FAIL на повторном монтировании WebGL после reload (видимый SVG, таймаут). Не считать полноценным PASS.
- Целевые unit: 2 PASS, 1296 профилей. Полный regression завершился с ошибкой worker (exit 3221226505); Windows также отдельно сообщила 800705af. Не доказано, что одно стало причиной другого. Требуется отдельный повтор после освобождения ресурсов. Один disposable Chrome профиль не удалось удалить полностью, его лог сохранён.
- Production build PASS. Предупреждение Avatar3D chunk ~842 kB. Экспериментальные маркеры не входят в JS сборки. HTTP 200 и SHA нового GLB; cross-site и прямой доступ к ZIP / BLEND — 403.

## Как посмотреть
На компьютере разработки: http://127.0.0.1:5188/?avatarFoundation=3&avatarFoundationRelief=1 . Раздел Герой. Параметр avatarFoundationRelief=0 выключает только рельеф. Рабочий режим — локальная проверка; сервер порта 5173 и исходный GLB сохранены.

## Не принято
Пластиковая кожа/глаза, грубые брови, волосы и обувь, недостаточно выраженный рельеф в отдельных ракурсах; поза статична. Поворот плеча на 6° уже добавил 1 пересечение, поэтому опускание рук отвергнуто. Нужны корректирующие формы плеч, полноценная поза/анимация, оценка кожи и одежды, проверки solid reload, проверка физического Android и полноценная регрессия. Нет основания утверждать AAA или релиз.

Подробные результаты и пути/байты/SHA-256: RECEIPT.json. Не переносить локальные исходники и QA файлы в public.
