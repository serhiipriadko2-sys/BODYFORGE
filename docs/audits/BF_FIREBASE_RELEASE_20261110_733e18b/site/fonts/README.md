# BODYFORGE self-hosted typography

Unmodified variable WOFF2 subsets downloaded from the official Google Fonts service on 2026-10-26. Font files are distributed under SIL Open Font License 1.1; full copyright and license notices are included alongside them. No fonts are requested from Google by the application at runtime.

- Manrope: body/interface, declared weights 400-800. Upstream: https://github.com/googlefonts/manrope
- Unbounded: display headings/wordmark, declared weights 500-800. Upstream: https://github.com/googlefonts/unbounded
- Included subsets: Latin and Cyrillic. Other scripts use the CSS system fallback.
- CSS aliases `BF Manrope` and `BF Unbounded` identify local face definitions; the binary names are unchanged.

Source CSS:
`https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&family=Unbounded:wght@500..800&display=swap`
