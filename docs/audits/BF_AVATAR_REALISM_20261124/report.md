# BODYFORGE — обновление 3D-бойца

Сборка для просмотра на ПК — http://127.0.0.1:5201/. Откройте «Герой» и переключите «Полный рост» на «Портрет». Примеры взяты из локального Chrome. Для максимальной прокачки использован отдельно созданный тестовый профиль.

- `before-portrait.png` и `after-portrait.png` — сравнение портрета при одинаковой ширине экрана и настройках внешности.
- `after-full.png` и `after-level5-full.png` — исходный и максимальный уровни. Поворот на кадрах отличается.
- `after-level5-side.png` — боковой ракурс максимального уровня.

## Модель и воспроизводимость

Blender 5.2 LTS считывает существующий MakeHuman GLB. `scripts/author-strand-groom.py` строит две объёмные причёски на поверхности конкретной головы. Обе экспортируются в `bodyforge-strand-groom.glb` с нормалями и цветами вершин. `scripts/bake-portrait-skin.py` проецирует щетину на существующую UV-развёртку. Карта заменяет прежнее альбедо для основной модели. Сбой файла переводит загрузчик на исходные ресурсы.

Оба генератора проверяют SHA-256 входных данных. Новые детали авторские. Исходные данные взяты из ранее допущенных CC0 ресурсов. Их происхождение зафиксировано в `docs/AVATAR_ASSET_LICENSE.md` и `public/assets/athlete-realism-source.md`. Для воспроизведения используйте новый выходной путь, генераторы откажутся перезаписывать существующий файл.

```powershell
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python scripts/author-strand-groom.py -- public/assets/bodyforge-athlete-efficient.glb .bodyforge-qa/repro-groom.glb
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python scripts/bake-portrait-skin.py -- public/assets/bodyforge-athlete-efficient.glb public/assets/athlete-skin-detail.jpg .bodyforge-qa/repro-portrait.jpg
```

Четыре группы прокачки управляют отдельными полями локального смещения. Поля масштабируются по уровням 0–5 и пересчитываются от исходных вершин. Для тела и одежды применяется одинаковое смещение в координатах рига. Веса костей и UV остаются исходными. Нормали корректируются через производную деформации. Пропорции глаз, пальцев и обуви проверены отдельно. Причёска прикреплена к голове. Предплечья опущены поворотом костей. Игровые цены и сохранения проходят существующий путь.

Портрет в сбалансированном режиме использует карту мягких теней 1024×1024. Просмотр в полный рост и экономный режим обходятся без этой карты. Аватар рисуется по событиям. На основном пути два прежних файла волос больше не загружаются. Новые волосы и альбедо вместе весят 1 089 395 байт, прежние два файла волос и альбедо весили 1 362 001 байт. Эти суммы описывают только перечисленные ресурсы.

Источники — [glTF PBR](https://www.khronos.org/gltf/pbr/), [экспорт glTF из Blender](https://docs.blender.org/manual/en/3.0/addons/import_export/scene_gltf2.html), [лицензия MakeHuman](https://www.makehumancommunity.org/about/license.html).

## Границы проверки

Сборка прошла тесты на Windows и в Chrome 157 с программным WebGL. `qa:avatar` использует диагностический импорт из `/src`, поэтому первый запуск на production preview завершился exit 12. Повторная проверка выполнялась на Vite dev. В `receipt.json` перечислены команды, выходные коды и SHA-256. Физический Android и время работы GPU не измерялись. Кадры показывают улучшенную игровую модель. Для сравнения с реалистичными AAA-портретами остаются заметны ограничения исходной геометрии лица и материалов глаз.
