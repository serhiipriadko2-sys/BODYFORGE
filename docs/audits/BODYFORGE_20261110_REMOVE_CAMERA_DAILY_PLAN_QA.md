## A / Problem

По скриншоту пользователь запросил убрать карточку **«ПЛАН НА СЕГОДНЯ / ТВОИ ПОВТОРЕНИЯ»** с экрана **«Камера»**. До исправления `src/App.tsx` загружал `DailyPlanBoard` при созданном бойце, а плитка «Цели дня» на «Горне» вела к `#daily-plan`.

**Не путать с «Миссии» и «Шаги / Путь бойца»**: они должны оставаться на «Камере». Удаление пользовательского UI не означает удаление записанных тренировок, личного профиля, XP или старой настройки `bodyforge:daily-plan:v1`.
