# BODYFORGE — физические испытания BF-604

Статус: NOT_RUN. Никакой результат телефона не подставляется из браузерных тестов.
Цель: проверить на отдельном тестовом профиле реальный WebView/Chrome, сохранения, лицензии и поведение при смене сети.

## Перед началом

- Подключить тестовый Android по USB, разблокировать и подтвердить отладку только для доверенного компьютера. Проверить наличие одного согласованного устройства командой adb devices -l. Серийный номер не помещать в публичный отчёт.
- Сверить SHA-256 APK и статус debug-кандидата с квитанцией. Не удалять установленное приложение, не очищать его данные. Не обновлять чужую или рабочую копию без согласия владельца и проверенного экспорта сохранения.
- Для измерений использовать искусственный тестовый профиль. Не записывать кадры камеры, личные медицинские сведения, необработанные данные Health Connect.

APK и web-пилот — разные поверхности. Нельзя считать прохождение одной прохождением другой. Проверки на реальном устройстве возможны после его подключения и отдельного согласования установки/тестов. Для каждой строки записать PASS/FAIL/NOT_RUN, версию Android, версию WebView/Chrome, идентификатор сборки, наблюдение и ссылку на безопасную квитанцию. Не переносить старый прогресс и не использовать личные медицинские данные в тесте.
