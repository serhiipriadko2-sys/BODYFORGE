## Следующая анатомическая основа — выполненная диагностика

Прочитаны обе исходные Blender-сцены art/bodyforge-athlete-realistic.blend и art/bodyforge-athlete-detail.blend: тело в каждой имеет 64607 вершин, 96224 треугольника, 0 shape keys. Триангуляция сама по себе не доказывает плохой внешний вид; она и отсутствие редактируемых форм усложняют анатомическую скульптуру.
Из фактических экспортированных V2 массивов создан отдельный growth-basis-diagnostic.blend, проверен повторным открытием в Blender. 4 mesh-объекта (тело и футболка на каждый build), по 6 shape keys: Basis, ARMS_L5, CORE_L5, LEGS_L5, BACK_L5, ALL_MAX_RESIDUAL_ONLY. Ручная синхронизация тела/одежды; позированная геометрия без рига и UV, только диагностический clay. Не готовая новая модель и не runtime replacement. Ошибка простого сложения независимых форм при all-max: тело max 1.7658 мм (RMS 0.18494 мм), shirt max 1.7360 мм; смешанный (3,1,2,4): тело max 0.8222 мм, shirt max 0.7834 мм. Добавочный остаток воспроизводит all-max с максимальным расхождением <0.00012 мм по проверенным координатам; он валиден для этой конечной точки, не для всего диапазона.
Следующая гипотеза — новая общая quad-основа в расслабленной A-pose, редактируемые независимые анатомические формы и отдельные корректоры совместной деформации, после чего bake микродеталей и экспорт rigged glTF. Не просто масштабировать нынешнюю сетку. Сопоставить лицо/торс/силуэт и бюджет WebGL2 на одинаковых ракурсах.
