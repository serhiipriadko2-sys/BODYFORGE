# BODYFORGE: установка на экран телефона

## Android
1. Открой опубликованный HTTPS-адрес BODYFORGE в Chrome.
2. Открой меню браузера и выбери «Установить приложение» или «Добавить на главный экран» (название зависит от версии).
3. Запускай BODYFORGE с созданного значка. Поддерживаемые браузеры открывают веб-приложение в отдельном окне.

## iPhone
1. Открой тот же HTTPS-адрес в Safari.
2. Нажми «Поделиться» → «На экран „Домой“» и подтверди.

## Резервная копия перед очисткой данных или сменой телефона
1. Создай бойца и открой вкладку «Горн»; внизу главного экрана найди блок «СОХРАНИ СВОЕГО БОЙЦА».
2. Нажми «ПОДГОТОВИТЬ РЕЗЕРВНУЮ КОПИЮ», дождись проверки локального хранилища.
3. Нажми «СКАЧАТЬ ПОДГОТОВЛЕННЫЙ JSON» и убедись, что файл появился в «Загрузках».
4. Если приложение сообщает о неполной копии, не очищай хранилище: часть данных не удалось прочитать.

JSON содержит профиль, сырые строки основных и резервных сохранений, журнал результатов и данные IndexedDB (если доступны), настройки внешности/оформления, ручные шаги и дневной план. Файл может содержать имя персонажа и историю тренировок — храни его как личный документ. **Автоматический импорт JSON не реализован:** скачивание само по себе не переносит прогресс на новое устройство.

## Проверка скачанной резервной копии (без восстановления)
1. После двух нажатий «Подготовить» и «Скачать» найди JSON в папке «Загрузки» телефона или компьютера.
2. В BODYFORGE открой «СОХРАНИ СВОЕГО БОЙЦА» → «ПРОВЕРИТЬ СКАЧАННЫЙ JSON» и выбери скачанный файл.
3. При результате «Структура ... проверена» файл содержит ожидаемые разделы и отметки доступности хранилищ; проверь дату и число записей. Файл не отправляется на сервер и не заменяет прогресс.
4. Если показана «копия неполная» или ошибка JSON, **не очищай исходные данные браузера**. Повтори экспорт, когда другие вкладки закрыты и хранилища доступны. Сохранённые повреждённые исходные байты не исправляются автоматически.

Проверяется формат BODYFORGE v1, основные записи и признаки согласованности. Нельзя проверить подлинность наград или гарантировать восстановление: **импорт JSON пока не реализован**. Проверка ограничена файлами до 16 МБ, чтобы мобильный браузер не загружал чрезмерно большие файлы в память.

## Проверка выбранной камеры во время тренировки
При переключении на «Селфи», «Основная» или обнаруженный объектив BODYFORGE читает фактические настройки видеопотока, когда браузер разрешает это сделать.

- **«Браузер подтвердил»** — настройки потока совпадают с выбранным объективом.
- **«Не подтвердил»** — браузер не предоставил сведения: камера работает, но проверь изображение самостоятельно. Выделенная кнопка в таком случае означает *запрос*, а не доказанное положение камеры.
- **«Открыл другой объектив»** — настройки потока не совпали с запросом. Неверная кнопка не выделяется как выбранная. Проверь изображение и повтори выбор.

Переключение не обнуляет уже засчитанные повторения, но возвращает калибровку тела в исходное состояние; удержание планки начинается заново. Идентификаторы камер не записываются в диагностический текст или резервную копию прогресса. Виртуальная камера браузерных тестов не доказывает работу физических объективов Android/iPhone.

## Ограничения
- Это устанавливаемое **веб-приложение**, не APK и не публикация в Google Play или App Store.
- **Офлайн-режим не реализован**: service worker и принудительное кэширование намеренно не добавлены. Для загрузки приложения и модели распознавания нужен интернет.
- Прогресс и настройки пока локальные для конкретного браузера и адреса сайта. Между устройствами и браузерами они не синхронизируются. Не удаляй данные браузера до экспорта прогресса.
- Камера требует HTTPS, разрешения браузера и совместимого устройства. Доступные упражнения перечислены в каталоге. Распознавание экспериментальное: точность новых детекторов на реальном телефоне ещё не подтверждена.
- Появление кнопки установки зависит от браузера и его критериев; манифест не гарантирует её на каждом устройстве.

## Проверка перед релизом
- `npm test` — модульные проверки.
- `npm run build` — сборка; проверяет наличие статических ресурсов в `dist`.
- `npm run qa:pwa` — сверка манифеста и значков с `dist`.
- `$env:BODYFORGE_QA_ORIGIN='http://127.0.0.1:5173'; npm run qa:pwa` — дополнительная проверка локального HTTP-сервера.
- `npm run qa:mobile` — браузерный сценарий камеры, прогресса и 3D.
- `powershell -File scripts/generate-pwa-icons.ps1` — пересоздать PNG из векторных исходников; требует локальный Chrome и Windows PowerShell.

**Релиз:** наличие файлов в рабочей папке не означает публикацию в Firebase. Перед обновлением Hosting нужна отдельная проверка точного источника, архив/preview для отката и подтверждение целевого сайта.
