# BODYFORGE — проверка восьми упражнений на настоящей камере

Обновлено: 27.10.2026. **Это инструкция для ручного испытания, а не подтверждение его прохождения.**
Программный распознаватель работает по 2D-точкам MediaPipe и не оценивает безопасность техники как тренер или врач.

## Перед проверкой

1. Открой BODYFORGE на устройстве с камерой по **HTTPS или localhost**. Простой адрес `http://192.168.x.x:5173` на телефоне обычно не даёт безопасного контекста для камеры. Если проверяешь в Chrome на своём ПК, используй `http://localhost:5173`.
2. Поставь телефон на устойчивую опору; не держи в руке. Обеспечь хорошее освещение, чтобы суставы не исчезали на каждом движении.
3. Убедись, что экран показывает выбранное упражнение и его цель. Для обычных движений — 20 повторений, для планки — 30 секунд.
4. Перед тестированием каждого режима полностью останавливай предыдущую тренировку. **Не выполняй 20 повторений специально ради теста сохранения**: сначала достаточно 5 медленных движений.
5. При боли или головокружении прекращай упражнение. Не пытайся подстроиться под счётчик ценой неудобной техники.

## Рекомендуемое положение камеры

| Упражнение | Где поставить телефон | Что должно быть видно | Признак зачёта |
| --- | --- | --- | --- |
| Приседания | Вертикально, сбоку / 45° | Плечо, таз, колено, стопа | Согнул ноги и выпрямился |
| Выпады | Вертикально, сбоку | Таз, оба колена, обе стопы | Согнул колено и вернулся в стойку |
| Отжимания | Горизонтально, сбоку и ближе к полу | Плечо, локоть, кисть, таз, стопа | Согнул и выпрямил руки |
| Прыжки с разведением | Вертикально, спереди | Оба запястья, плечи, таз, обе стопы | Руки вверх *и одновременно* ноги в стороны, затем назад |
| Высокие колени | Вертикально, спереди / 45° | Таз, оба колена, обе стопы | Поочерёдный подъём и опускание коленей |
| Подъёмы корпуса | Горизонтально, сбоку | Плечо, таз, колено, стопа | Плечи поднялись и опустились |
| Подъёмы ног | Горизонтально, сбоку | Плечо, таз, колено, стопа | Ноги поднялись и опустились |
| Планка | Горизонтально, сбоку | Плечо, опорный локоть, таз, стопа | Таймер непрерывно достигает 30 секунд |

В приложении интерфейсное окно может оставаться вертикальным **9:16**, даже если телефон/камера отдаёт горизонтальный поток **16:9**. Для упражнений лёжа включи «Показать весь кадр», если обрезаны стопы или кисти.

## Контрольный прогон каждого упражнения

Для каждого режима проверь **пять медленных повторений** и **пять обычных**. После этого остановись в исходной позе на 5 секунд — счёт не должен расти, пока ты неподвижен.

Отдельно проверь отрицательные случаи:
- **Прыжки с разведением:** поднятие одних рук без разведения ног и разведение одних ног без поднятия рук — не должны засчитываться.
- **Высокие колени:** два подъёма одной и той же ноги подряд не должны ошибочно восприниматься как чередование.
- **Отжимания и упражнения лёжа:** убери локоть или стопу из кадра; приложение должно подсказать, какого сустава не хватает, а не придумать повторение.
- **Планка:** потеря позы должна обнулить текущий отсчёт. Краткое исчезновение одной точки может поставить время на паузу; невидимое время не засчитывается.
- **Все режимы:** отмена до достижения цели не должна начислять XP или монеты.

## Если счёт не идёт

- Проверь, что обе кисти/стопы видны, а суставы не у самого края кадра.
- Для прыжков с разведением попробуй подойти немного ближе — но не обрезай поднятые руки.
- Для отжиманий, планки и упражнений на пресс проверь боковой ракурс и горизонтальную ориентацию источника камеры.
- Если сменил объектив, подожди повторную калибровку и вернись в исходную позу.
- Если счётчик завышает результат, останови тест и зафиксируй **какое движение было засчитано неправильно**; не компенсируй ошибку дополнительными повторениями.

## Отладка разработчиком (Windows + Chrome)

В каталоге `C:\github\BODYFORGE`:

```powershell
npm test -- --maxWorkers=1 --no-file-parallelism
npm run build
npm run qa:exercise-catalog
npm run qa:exercise-motion
npm run qa:camera-runtime
npm run qa:mobile
```

Последние четыре команды используют браузерные тесты с имитацией камеры. Они проверяют программу, **но не заменяют физическую проверку**, описанную выше. Подлинные файлы и награды пользователя для них не требуются.
